title: Rules
description: >-
  Every rule decolint ships, what it checks, and why.
---

Each rule belongs to one category, which sets its severity unless a
[config file](../getting-started.md#2-turn-on-the-checks-you-want) overrides
it; only `correctness` is enabled out of the box. A rule that names a platform
runs only when that platform is selected with `--platform`.
